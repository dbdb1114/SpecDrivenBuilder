# 제약 — 작업 단위 E (PROMPT.md 에서 옮김, 2026-11-13)

## 범위
- FastAPI 로 그래프를 노출한다: 실행 시작, 질문 묶음 받기, 답 제출, 확인 화면 받기 · 답하기, 산출물 받기.
  `api/` 는 요청 파싱 → 그래프 호출 → 응답 직렬화만 한다.
- 프론트엔드 타입은 OpenAPI 에서 생성한다. 규격을 프론트엔드에 손으로 다시 적지 않는다.
- 프론트엔드 질문 화면: 질문 묶음(1~10개), 선택지 + 고정 선택지 "알아서 정해 주세요" + 직접 입력, 추천 표시,
  여러 개 고르기, "그만 묻고 만들어 주세요".
- 프론트엔드 확인 화면: 스펙 항목 요약, 고칠 항목 고르기.

## 건드리지 않는 것
- 그래프 조립(`graph/build.py`), State 스키마, 스펙 항목 · JSON 규격 모델, 노드 파일 전부
- `graph/main.py`
- `visual`(색 견본 · 레이아웃 그림)과 `preview`(미리보기) 그리기 (F 의 범위). 이 필드가 와도 화면이 깨지지 않게만 한다
- 막힌 파일을 고쳐야 하거나 범위 밖으로 나가야 하면 중단하고 묻는다 (다른 worktree 에서 동시 작업 중)
