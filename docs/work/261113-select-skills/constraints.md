- 공통 스킬 목록과 첫 공통 스킬. Claude Code 와 Codex 양쪽에서 실행 검증한 것만 올린다.
- `generate_artifacts` 가 스킬 목록을 받아 스킬을 여러 개 쓴다: 공통 스킬은 그대로 넣고, 새로 쓰는 스킬은 이름과
  "언제 쓰는지"를 받아 본문을 쓴다.
