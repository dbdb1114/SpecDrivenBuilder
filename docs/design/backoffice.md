# 백오피스 — 노드 설정과 참조 자료를 고치는 로컬 화면

> 결정 (2026-11-17): 노드 단위 설정, 공통 항목·공통 스킬·색 조합 같은 참조 자료, 프롬프트를 화면에서 보고 고친다.
> **로컬 전용 개발 도구**로 만든다. 구현 전 — 작업 단위 K~N (`work-units.md`).

## 왜

- 한 사이클의 비용과 품질은 노드마다 다른 것에 달려 있다 (모델, 프롬프트, 고를 목록). 지금은 파일을 직접 열어 고치고
  터미널 명령으로 호출 기록을 본다.
- 프롬프트는 한 줄만 바꿔도 결과가 크게 달라진다. `select_stack` 에서 돌아가는 기준을 한 줄 좁혔더니 꼭 필요한 질문이
  8번 중 8번 사라졌다 (`docs/work/261117-stack-roundtrip/plan.md`). 고친 것을 바로 견줘 볼 수단이 필요하다.

## 로컬 전용인 이유

운영에서도 쓰는 관리 화면은 설정을 DB 로 옮기고 로그인·변경 이력·검증 후 반영 절차를 만들어야 한다. 운영 환경은 아직 정하지 않았다.
로컬 전용이면 이 넷이 필요 없다.

| 필요한 것 | 로컬 전용에서는 |
|---|---|
| 저장소 | 화면이 레포의 파일을 그대로 고친다. 원본은 계속 파일이다 |
| 변경 이력 · 검토 | git 이 맡는다. 고친 내용은 `git diff` 에 보이고 커밋은 사람이 한다 |
| 로그인 | 없다. 환경 변수로 켰을 때만 동작하고, 이 컴퓨터에서 온 요청만 받는다 |
| 검증 후 반영 | 고쳐도 작업 폴더만 바뀐다. 품질 회귀를 돌리고 커밋해야 다른 사람에게 반영된다 (루트 `AGENTS.md` "품질 판정" 그대로) |

포기하는 것: 배포한 서버에서는 쓸 수 없다. 운영용 관리 화면이 필요해지면 로그인과 저장소를 붙이는 별도 작업이다.

## 다루는 것

| 대상 | 원본 | 화면에서 하는 일 | 저장 전 검사 |
|---|---|---|---|
| 노드 설정 | 노드 설정 파일 (작업 단위 K 에서 만든다) | 노드별 모델 · effort · 돌아가는 횟수 상한 | 값의 범위 |
| 공통 항목 | `builder/prompts/common_items.json` | 언제 넣는가 · 질문 문구 · 선택지 · 기본 방향 | 지금 있는 규격 검사 (`common_items.py`) |
| 공통 스킬 | `builder/templates/skills/<이름>/SKILL.md` | 추가 · 이름과 "언제 쓰는지" · 본문 | frontmatter 필수 필드 |
| 색 조합 | 색 조합 목록 (만든 뒤) | 색 고르기 · 대비 계산 · 미리보기 틀에 입혀 보기 | 대비가 기준에 못 미치면 저장하지 않는다 |
| 프롬프트 | `builder/prompts/<노드명>.md` | 편집 · git 과 달라진 부분 보기 · 재생 비교 | 없음 — 판정은 재생 비교와 품질 회귀로 한다 |
| 호출 기록 | `builder/output/_traces/<run_id>.jsonl` | 실행별 호출 · 토큰 · 비용 · 프롬프트와 응답 전문 | 읽기만 한다 |

- 배치 틀 6개는 프론트엔드 코드라 보기만 한다.
- **재생 비교:** 호출 기록에 남은 입력을, 고치기 전 프롬프트(git 의 것)와 고친 프롬프트에 똑같이 보내 응답을 나란히 본다.
  같은 입력을 여러 번 보내 흔들림도 본다. 실제 LLM 호출이라 비용이 든다 — 화면에 예상 호출 수를 보여 주고 사람이 누를 때만 돈다.
  재생 비교는 품질 회귀를 대신하지 않는다. 그 노드의 응답만 견주고 뒤 노드에 미치는 영향은 보지 않는다.

## 규칙

- 백오피스는 `api/` 아래의 별도 라우터다. 환경 변수로 켜지 않으면 등록하지 않는다 (기본은 꺼짐).
- 쓰기는 위 표의 원본 경로에만 한다. 화면이 보낸 경로를 그대로 쓰지 않고, 이름을 받아 정해진 폴더 안의 파일로 바꾼다.
- 파일을 고치면 그 뒤에 시작하는 실행부터 반영된다. 진행 중인 실행은 시작할 때의 설정을 따른다.
- 실행마다 쓴 노드 설정을 호출 기록에 남긴다 (모델은 이미 남는다). 결과가 달라졌을 때 설정 때문인지 볼 수 있어야 한다.
- 화면은 빌더 프론트엔드와 같은 디자인 토큰을 쓴다. 사용자가 보는 화면(홈 · 스튜디오 · 완료)에는 백오피스로 가는 길을 두지 않는다.

## 미결정

- 노드 설정 파일의 위치와 형식 (작업 단위 K 의 계획에서).
- 프롬프트를 고친 뒤 품질 회귀를 화면에서 돌릴지 — 케이스 4개 × 전후는 약 2달러, 10분쯤 걸린다.
