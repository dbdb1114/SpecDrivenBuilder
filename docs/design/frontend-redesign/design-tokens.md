## 글꼴 (Google Fonts)

- 제목: `Space Grotesk` 700 → 한글은 `Noto Sans KR` 900 으로 떨어짐. 자간 `-0.045em`, 줄간 1.02
- 본문: `Noto Sans KR` 400/500/700
- 코드·라벨·파일명: `JetBrains Mono` 400/600, 라벨은 11px · 자간 .08em · 대문자

크기: 히어로 `clamp(48px, 8.4vw, 124px)` · 완료 화면 `clamp(44px, 7vw, 104px)` · 본문 15px · 라벨 11–13px

## 모서리 · 간격

- 패널 22px · 입력창 14–20px · 버튼 12–16px · 칩/알약 999px · 작은 상자 7–10px
- 패널 사이 18–20px, 페이지 좌우 `clamp(16px, 4vw, 48px)`, 최대 폭 1280–1400px

## 밝은 테마 (2026-11-14 추가)

시안은 어두운 테마 하나였다. 밝은 테마는 같은 토큰 이름에 다른 값을 준다 (`src/index.css` 의 `:root[data-theme="light"]`).

- 바탕 `#F6F6F1`, 면 `#FFFFFF`, 글자 `#131316`. 격자·선은 같은 구조로 밝게.
- 형광 강조색(`#D4FF3A`)은 밝은 바탕 위 글자로 읽히지 않는다. 그래서 강조색을 셋으로 나눈다.
  - `--ac` 글자·선: 어두운 테마 `#D4FF3A`, 밝은 테마 `#456E00` (바탕 대비 약 5.6:1)
  - `--ac-fill` 채운 면: 두 테마 모두 `#D4FF3A`
  - `--on-ac` 채운 면 위 글자: 두 테마 모두 `#0A0A0C`
- 처음 값은 저장된 선택, 없으면 시스템 설정. 머리글의 버튼으로 바꾸고 `localStorage` 의 `theme` 에 저장한다.
- 디자인 미리보기(`Preview`)와 색 견본(`Visual`)은 사용자가 만들 프로그램의 색이라 테마를 따르지 않는다.
