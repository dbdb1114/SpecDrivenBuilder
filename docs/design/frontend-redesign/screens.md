# 화면별 명세

공통 헤더: 로고(→ 홈) · 제품명 · 단계 표시 `01 아이디어 / 02 인터뷰 / 03 생성 / 04 다운로드`
(현재 단계 = 강조 배경, 지난 단계 = 흰 테두리, 남은 단계 = 흐린 글자). 배경 64px 격자선.

## 01 홈 `/`

- 배지 "FOR VIBE CODERS" + 한 줄 소개
- 헤드라인 3줄, 줄마다 순차 등장. 셋째 줄 단어가 `spec.md → AGENTS.md → SKILL.md → CLAUDE.md` 로 세로 회전 (7초 주기)
- 아이디어 입력창 + "설계 시작" 버튼. 비어 있으면 버튼 비활성 (시안은 예시로 채웠지만 실제는 비활성)
- 예시 칩 4개: 누르면 입력창에 채워지기만 함 (바로 제출하지 않음)
- "어떻게 동작하나요" 3칸 (말하기 / 답하기 / 넘기기)
- 하단 강조색 띠: 파일명이 가로로 무한 스크롤 (장식, `aria-hidden`)
- 오른쪽 위 점선 원 궤도 회전 (장식)

## 02 인터뷰 / 03 생성 중 `/s/:id`

2단: 왼쪽 대화(넓게) · 오른쪽 산출물 패널. 폭이 좁으면 세로로 쌓임.

왼쪽 대화
- 상단: PROJECT 라벨 + 아이디어 제목(말줄임) · 진행 바 + %
- 메시지 목록: 봇(왼쪽, "SB" 아바타, 어두운 말풍선) / 사용자(오른쪽, 흰 말풍선). 새 메시지 자동으로 맨 아래 보이게
- 봇 응답 대기 중: 점 3개 튕기는 말풍선
- 하단 답변 도크 (02):
  - `Q{n} · {key}` 라벨
  - 선택지 카드: 번호 상자 + 문구 + 추천이면 "추천" 배지와 강조색 테두리. 순차 등장
  - "직접 입력" 입력창 + 보내기(아이콘 버튼, `aria-label`)
  - 응답 대기 중에는 도크 숨김 (중복 전송 방지)
- 하단 생성 표시 (03): 회전 스피너 + "산출물을 만드는 중 — {현재 파일명}"

오른쪽 산출물 패널
- 폴더명 + `{완료 수} / 5 완료`
- 파일 5행: 아이콘 · 파일명 · 설명 · 상태 알약 (대기 / 작성 중 / 완료). 완료되는 순간 강조색으로 번쩍
- 03 에서는 패널 위로 스캔 라인이 반복해서 내려감
- `spec.md — 실시간 작성` 창: 답변이 쌓일 때마다 `- {key}: {answer}` 줄 추가 + 깜빡이는 커서
  - **[미확인]** 실제 spec 은 마지막에 생성되므로, 이 창은 "지금까지 받은 답 요약"이다. 백엔드 생성물처럼 보이게 하지 말 것

## 04 다운로드 `/s/:id/done`

- "● BUILD COMPLETE · 5 FILES" + 헤드라인 3줄 (2·3줄 흐린 색)
- 버튼: `{slug}.zip 다운로드`(주) · `미리보기·수정`(→ 05) · `새 프로젝트`
- 실행 안내 3단계 카드 (코드 한 줄씩, 가로 스크롤):
  1. `unzip {slug}.zip && cd {slug}`
  2. `claude`
  3. `"spec.md 대로 만들어줘"`
- 오른쪽: zip 내용 파일 목록 + spec 미리보기 상자

## 05 리뷰 `/s/:id/review`

3단: 파일 탭 · 문서 뷰어 · 말로 고치기. 좁으면 세로로 쌓임.

- 헤더 추가 요소: `/ {slug}` · 버전 알약 `v{n}` · "{n}개 파일 수정됨" · "확정하고 다운로드"
- 파일 탭: 파일명 + 설명. 선택 탭 = 강조색 테두리. 수정된 파일 = 퍼지는 점
- 문서 뷰어
  - 상단: 파일명 · 줄 수 · `읽기 / 원문` 토글 (읽기 = 제목·목록 서식, 원문 = 고정폭)
  - 줄 번호 + 줄. 줄 클릭 = 선택(흰 왼쪽 선), 다시 클릭 = 해제
  - 제안이 있을 때: 상단 "제안 · {파일} · n줄 변경" 바 + 되돌리기/적용. 추가 줄 = 강조색 배경·`+`, 삭제 줄 = 주황 배경·`−`·취소선
- 말로 고치기
  - 대화 목록 (02 와 같은 말풍선, 사용자 말풍선 위에 선택 줄 인용 `L{n} …`)
  - 예시 칩 3개 → 바로 요청
  - 선택한 줄이 있으면 `L{n} {내용}` 칩 + 해제 버튼, 입력 placeholder 가 "이 줄을 어떻게 바꿀까요?"로 바뀜
  - 입력창 + 보내기
- 확정 시: 하단 중앙 토스트 `{slug}.zip (v{n}) 받는 중` + 진행 막대 + "새 프로젝트" 링크

## 접근성 (전 화면)

- 모든 클릭 대상은 `<button>` / `<a href>`, 최소 44px
- 아이콘 전용 버튼에 `aria-label`, 장식 SVG 에 `aria-hidden`
- 입력창마다 `<label>` (시각적으로 숨겨도 됨)
- `prefers-reduced-motion: reduce` 이면 모든 애니메이션·전환 끔
- 포커스 링: 강조색 2px, offset 3px
